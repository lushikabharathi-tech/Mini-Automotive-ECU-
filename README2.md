# Mini-Automotive-ECU-
Virtual ECU Simulation project using arduino 
Virtual ECU Project

Project Overview

This project simulates a basic Electronic Control Unit (ECU) using Arduino in the Wokwi simulator.

Components Used

- Arduino board
- Push button
- LEDs
- Resistors
- Jumper wires

Features

- Simulates basic ECU input and output behavior.
- Uses a push button as an input.
- Controls LEDs as output indicators.
- Runs in a virtual environment using Wokwi.

Software Used

- Arduino IDE
- Wokwi Simulator
- GitHub

Project Files

- "sketch.ino" — Arduino program code.
- "diagram.json" — Circuit diagram configuration.

How to Run

1. Open the project in Wokwi.
2. Start the simulation.
3. Press the push button to test the circuit.
4. Observe the LED indicators.
